# 🛡️ Abhayam — Women’s Safety and Emergency Assistance System

**Abhayam** is a real-time safety and alert system designed to help women feel safer in public and private spaces. This project integrates emergency assistance features with location tracking and intelligent alert mechanisms to enable quick response in case of distress.

---

## 🎯 Project Objectives

- Ensure personal safety for women using technology.
- Enable real-time location tracking during emergencies.
- Trigger SOS alerts to trusted contacts or emergency services.
- Provide fast and simple user access via mobile interface

---

## 🔍 Key Features

- 🚨 **One-Tap SOS Button**: Sends an immediate emergency alert with location to pre-selected contacts.
- 📍 **Live GPS Tracking**: Continuously shares real-time location after SOS activation.
- 📢 **Silent Alert Mode**: Triggers emergency notification without drawing attention.
- 📡 **SMS**:  system ensures SOS reaches 
- 📲 **Mobile App Interface**: Simple UI/UX for quick access during panic situations.

---

## 🛠️ Tech Stack

- **Frontend**: Flutter / Android (Kotlin or XML-based UI)
- **Location Services**: Google Maps API / Geolocation APIs
- **Notification Services**:  SMS Gateway APIs
---

## 🚀 How It Works

1. User presses the **SOS button** on the app or wearable.
2. Real-time location is fetched via GPS.
3. Alert is sent to emergency contacts via SMS or push notification.
4. Location continues to be updated until user marks themselves safe.
5. In case of no response, system can escalate alert to local authorities.

---

## 📌 Use Cases

- Women commuting alone at night.
- College students staying in hostels or PGs.
- Emergency situations like stalking, harassment, or accidents.
- Integration into community safety networks, NGOs, or state helplines.
